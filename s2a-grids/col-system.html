S2a Column Grid

COL container logic ranges: 12 cols (768px and up), 6 cols (below 768px) — mobile-first, no-query default with width >= range media queries above it.

Container Types
• Standard: Max 1920px content container (HD width is now the default; the separate HD toggle has been retired).
• Token offset: Max 1920px content container, margins driven by a spacing token per breakpoint (see the Margin Tokens widget below).
• Fluid: No max content container. (wip) maybe carousel or sliders etc. 2560 max
• Container Overflow: allowed to go beyond the viewport, flex grid + object-fit etc.

Margins
• Standard/HD containers: 83.4% width margins apply MD and up (≥768px); SM (below 768px) uses a fixed --spacing-lg padding.
• Token offset: padding-based margins per breakpoint, defaulting to --spacing-lg / --spacing-2xl / --spacing-4xl for SM / MD / LG, then switching to the 83.4% width rule at XL (≥1441px) — adjustable live via the Margin Tokens widget.

Breakpoints
• SM — no media query (mobile-first default, below 768px): 6 cols. True mobile, but also covers tablet portrait.
• MD — @media (width >= 768px): 12 cols. Tablet landscape range.
• LG — @media (width >= 1280px): 12 cols. Standard desktop range.
• XL — @media (width >= 1441px): 12 cols. HD/stress-test desktop range (up to 2560, used only as needed).

5. Breakpoint Layouts

Demonstrating how elements can adapt their proportions differently across desktop, tablet, and mobile breakpoints using `col-lg-*`, `col-md-*`, and `col-sm-*` classes.

Example A: 3-up to 2-up to Stacked

On Desktop (12 cols), we show 3 items in a row (4 cols each). On Tablet (12 cols), the first two take half the width (6 cols) and the third drops to a full row (12 cols). On Mobile (6 cols), they all stack (6 cols each).
